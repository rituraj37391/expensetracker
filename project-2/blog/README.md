# Little Stories

A React and Vite blog dashboard styled with Tailwind CSS.

## Run locally

Open a terminal in this project folder (`E:\VS Code\project-2\blog`), then run:

```powershell
npm install
npm run dev
```

The development server prints the local URL to open in your browser.

Run the production build and linter from the same folder:

```powershell
npm run build
npm run lint
```

The repository workspace root (`E:\VS Code`) does not contain a `package.json`.
Run npm commands from `project-2\blog`, where this app's `package.json` lives.
